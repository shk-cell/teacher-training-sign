교직원 연수실

1. 압축파일은 먼저 폴더 전체를 압축 해제하세요.
2. 교직원연수실.exe를 더블클릭하세요. Python 설치는 필요하지 않습니다.
3. 창이 열리면 서버가 자동으로 시작됩니다.
4. [자료 폴더 열기]를 누르고 PDF·PNG를 넣으세요.
   파일 하나가 연수 하나이며, 여러 이미지는 같은 하위 폴더에 넣으면 묶입니다.
   01.png, 02.png처럼 이름을 붙이면 순서대로 표시됩니다.
5. [주소 복사]를 눌러 선생님들께 보내세요.
   같은 학교 네트워크에서 접속할 수 있습니다.
6. [관리자 화면 열기]를 누르면 비밀번호 없이 바로 로그인됩니다.
   연수명·확인 문구를 수정하고 [한글 서명부 만들기]를 누르세요.
   이름과 서명 이미지가 정리된 연수명_서명부.hwpx가 내려받아집니다.
   한글에서 바로 열어 편집·인쇄할 수 있습니다. 엑셀·워드도 지원합니다.
7. [서버 중지] 또는 창 닫기로 종료합니다. 서명 기록은 보존됩니다.

저장 위치
- 연수자료: EXE 옆의 '연수자료' 폴더
- 서명·설정: EXE 옆의 'data' 폴더 (자동 생성)
- 오류 기록: data/server.log
- 백업: 프로그램을 종료한 뒤 EXE·연수자료·data를 함께 복사하세요.

다른 학교에 전달할 때
- 배포용 ZIP에는 프로그램과 사용안내만 있으며, 기존 서명·비밀번호·자료가 포함되지 않습니다.
- 해당 학교의 연수자료를 넣어 사용하세요.

접속이 안 되면
- 서버가 실행 중인지, 서버 PC가 절전 상태인지 확인하세요.
- 주소가 여러 개면 학교 내부망 IP를 선택하세요.
- 학교 담당자에게 Python 또는 교직원연수실의 내부망 TCP 접속 허용을 문의하세요.
- 기본 포트는 8000입니다. 포트 충돌 시 중지 상태에서 다른 포트를 입력해 시작하세요.
- 관리자 화면은 서버 PC에서만 접속할 수 있습니다.

서버를 다시 시작하면 관리자 비밀번호가 바뀝니다. 비밀번호는 주소로 직접 접속할 때만 필요합니다.
연수자료 상태(등록된 연수, 열 수 없는 자료)는 프로그램 창의 자료 카드에서 확인하세요.
EXE를 쓰기가 가능한 일반 폴더에 놓아 주세요.
