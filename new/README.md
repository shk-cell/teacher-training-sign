# 교직원 연수실 — 윈도우 프로그램

**교직원연수실.exe**를 더블클릭하면 윈도우 관리 창이 열리고 서버가 자동으로 시작됩니다.
CMD 창이나 Python 설치 없이 사용할 수 있습니다. Apps Script, 구글 계정, Node.js도 필요하지 않습니다.
선생님들은 브라우저에서 자료를 확인한 뒤 이름과 서명을 제출합니다. 기록은 실행한 PC에 저장됩니다.

## 처음 시작하기

1. **교직원연수실.exe**를 실행합니다. 배포용 ZIP을 받았다면 먼저 압축을 해제하세요.
2. **자료 폴더 열기**를 눌러 PDF·PNG를 넣습니다.
3. **주소 복사**를 눌러 교내 메신저로 공유합니다. 주소가 여러 개면 학교 내부망 IP를 선택하세요.
4. **관리자 화면 열기**를 누르면 비밀번호 입력 없이 바로 로그인됩니다. 연수명과 확인 문구를 수정하고 서명부를 내려받습니다.
5. **서버 중지**를 누르거나 창을 닫으면 종료됩니다. 저장된 서명은 다음 실행 때도 남습니다.

인터넷 없이 사용할 수 있습니다. 선생님들의 PC·휴대폰은 서버 PC에 접속할 수 있는 학교 네트워크에 있어야 합니다.
관리자 비밀번호는 서버를 시작할 때마다 새로 생성되며, 주소로 직접 접속할 때만 필요합니다. 등록된 연수와 열 수 없는 자료(암호·손상 PDF)는 프로그램 창의 자료 카드에 표시됩니다. 실행 중에는 프로그램 창을 유지하고 PC 절전 모드를 꺼 두세요.
포트는 서버가 중지된 상태에서 변경할 수 있습니다. 기본값은 8000입니다.

## 연수자료 폴더에 넣기만 하면 됩니다

```text
프로그램 폴더/
  교직원연수실.exe
  연수자료/
    정보보안 교육.pdf       ← PDF 한 개가 연수 한 개
    개인정보 안내.png       ← 이미지 한 개가 연수 한 개
    안전교육/               ← 하위 폴더 한 개가 연수 한 개
      01.png
      02.png
      03.pdf
  data/                     ← 자동 생성: 서명과 열람 기록
```

- PDF, PNG, JPG, JPEG를 지원합니다. 암호가 걸린 PDF는 암호를 해제해서 넣어 주세요.
- 자료를 **추가·교체·삭제하면 열어 둔 연수 목록에 약 4초 안에 자동 반영**됩니다. 서버를 재시작할 필요가 없습니다. 관리자 화면은 새로고침 버튼으로 갱신합니다.
- 여러 이미지를 묶으려면 바로 아래 하위 폴더에 넣습니다. 파일 이름순으로 연결하므로 `01.png`, `02.png`처럼 번호를 붙여 주세요. PDF와 이미지를 섞어도 됩니다.
- 하위 폴더 안에 또 만든 폴더는 읽지 않습니다.
- 관리자 화면에서 연수명과 확인 문구를 수정할 수 있습니다. 자료 내용은 PDF·이미지를 교체해서 수정합니다.
- 파일·폴더 이름을 바꾸면 **새 연수**가 됩니다. 이름을 유지하고 파일을 교체하면 같은 연수의 새 자료 버전으로 처리됩니다.
- 자료를 교체하면 열람 중이던 참여자는 처음부터 다시 확인해야 합니다. 연수명·확인 문구를 변경해도 진행 중인 열람은 다시 시작해야 합니다.
- 삭제해도 **이미 받은 이름·서명·제출 당시 연수명·확인 문구·자료 버전**은 남습니다. 관리자의 ‘자료 삭제됨’ 항목에서 서명부를 받을 수 있습니다. 제출 당시 PDF 원본을 별도로 보관하지는 않으므로 필요하면 자료도 따로 백업하세요.

## 서명부 내려받기

관리자 화면에서 연수별로 **한글 서명부 만들기(.hwpx)** 를 누르면 제출된 이름과 서명이 정리된 `연수명_서명부.hwpx`를 받습니다. A4 표에 번호·성명·서명 이미지·제출 일시를 넣고, 여러 쪽에서는 표 머리글을 반복합니다. 한글 프로그램에서 바로 열어 수정하거나 인쇄할 수 있습니다. 엑셀(.xlsx)과 워드(.docx)도 내려받을 수 있습니다.
이름·직접 쓴 서명 이미지·제출 일시가 함께 들어갑니다. 제출이 추가되면 다시 내려받으세요. 기존에 내려받은 파일을 자동 수정하지는 않습니다.

같은 제출을 통신 오류로 다시 보내도 한 건만 저장합니다. 다른 열람에서 같은 이름으로 새로 제출하면 별도로 보관합니다. 동명이인도 있으므로 이름만으로 덮어쓰지 않습니다.
쪽 넘김 기록은 열람 확인용이며 실제 독서 여부나 서명자의 신원을 인증하지는 않습니다.

## 저장과 백업

- `data/training.sqlite3`에 이름·서명·제출 일시와 설정이 저장됩니다. 외부 서비스로 전송하지 않습니다.
- **서버를 종료한 뒤** 프로그램 폴더 전체를 복사하면 자료와 기록을 함께 백업할 수 있습니다.
- 다른 학교에 새 프로그램을 전달할 때는 **교직원연수실_배포용.zip**을 전달하세요. ZIP에는 프로그램·사용안내·서체 저작권 안내·빈 자료 폴더만 포함하며 기존 자료·서명 기록은 포함하지 않습니다.
- 자료 링크를 아는 교내 사용자는 열람과 제출이 가능합니다. 제출 목록과 내려받기는 **서버 PC의 localhost 관리자 로그인**으로만 가능합니다.
- 학교 내부망 HTTP용 프로그램입니다. 공유기 포트 포워딩으로 인터넷에 공개하는 용도로 만들지 않았습니다.

## 접속이 안 될 때

1. 서버 PC에서 `http://localhost:8000`이 열리는지 확인합니다.
2. Windows 방화벽에서 교직원연수실의 학교 내부망 연결을 허용합니다. 필요한 경우 학교 담당자에게 TCP 8000 포트 접속 허용을 요청합니다.
3. 교직원 PC와 서버 PC 사이 통신이 허용되는지 확인합니다. 게스트 Wi-Fi·망 분리 환경에서는 차단될 수 있습니다.
4. 서버 PC의 IP가 바뀌면 프로그램 창의 현재 IP를 다시 공유합니다.
5. 8000 포트가 사용 중이면 중복 실행된 서버를 종료하거나 포트를 바꿉니다.

프로그램 창에서 서버를 중지한 뒤 포트를 변경할 수 있습니다. 관리자 비밀번호는 프로그램 창의 복사 버튼으로 확인합니다.

## 개발 및 검증

아래 명령은 `new` 폴더 안에서 실행합니다.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\pythonw.exe desktop.py
```

서버: Flask + Waitress / 자료 처리: PyMuPDF / 저장: SQLite / 엑셀: openpyxl / 워드: python-docx.
이전 구글 연동 버전은 한 단계 위의 `../legacy/`에 따로 보관했습니다. 기존 화면·설정·자료·Apps Script와 당시 사용 설명서가 들어 있습니다. 현재 로컬 서버는 `legacy/`의 파일을 사용하지 않습니다.

## EXE 다시 만들기 (개발자용)

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe build_exe.py
```

`교직원연수실.exe`와 `교직원연수실_배포용.zip`이 생성됩니다.
웹 화면과 Python 실행 환경은 EXE 안에 포함됩니다. 자료와 서명 데이터는 EXE 옆에 저장되므로 EXE를 교체해 업데이트할 수 있습니다.

메이플스토리 서체 Light·Bold를 원본 그대로 포함합니다. 별도 폰트 설치가 필요하지 않습니다. 서체 저작권과 사용 조건은 `THIRD_PARTY_NOTICES.txt`를 참고하세요.
