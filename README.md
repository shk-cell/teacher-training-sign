# 교직원 연수 서명 프로그램

버전별로 폴더를 나누어 보관합니다.

- **[new](new/README.md)**: 현재 윈도우 EXE 버전. `new/교직원연수실.exe`를 실행하세요. 다른 PC에는 `new/교직원연수실_배포용.zip`을 전달하면 됩니다. 연수자료는 `new/연수자료`, 저장 데이터는 `new/data`에 있습니다.
- **[legacy](legacy/README.md)**: 이전 GitHub Pages·Google Apps Script 버전과 기존 자료·사용 설명서.

현재 버전의 설치와 사용 방법은 [new/README.md](new/README.md)를 확인하세요.
