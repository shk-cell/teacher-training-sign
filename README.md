# 교직원 연수실 — 학교 내부망용 로컬 프로그램

`서버실행.bat`을 실행하고 표시되는 `http://학교PC의IP:8000` 주소를 선생님들에게 보내세요.
선생님들은 자료를 한 쪽씩 확인한 뒤 이름과 서명을 제출합니다. 자료와 제출 정보는 실행한 PC에 저장됩니다.
Python으로 실행하며 Apps Script, 구글 계정, Node.js는 필요하지 않습니다.

## 처음 시작하기

1. Windows PC에 **Python 3.11 이상**을 설치합니다. Python Launcher(`py`)도 함께 설치합니다.
2. **서버실행.bat**을 더블클릭합니다. 처음에는 인터넷으로 필요한 라이브러리를 설치합니다.
3. 실행 창에 나온 **선생님용 IP·포트 주소**를 교내 메신저로 공유합니다. IP가 여러 개 나오면 학교 내부망 IP를 사용합니다.
4. 관리자는 같은 PC에서 **http://localhost:8000/admin** 을 엽니다. 비밀번호는 서버 실행 창에 표시됩니다.
5. 서버 창에서 `Ctrl+C`를 누르거나 창을 닫으면 종료됩니다. 저장된 서명은 다음 실행 때도 남습니다.

첫 설치 후에는 인터넷 연결 없이 사용할 수 있습니다. 선생님들의 PC·휴대폰은 서버 PC에 접속할 수 있는 학교 네트워크에 있어야 합니다.
관리자 비밀번호는 서버 시작 때마다 새로 표시됩니다. 실행 중에는 서버 창을 유지하고 PC의 절전 모드를 꺼 두세요.

## 연수자료 폴더에 넣기만 하면 됩니다

```text
프로그램 폴더/
  서버실행.bat
  server.py
  연수자료/
    정보보안 교육.pdf       ← PDF 한 개가 연수 한 개
    개인정보 안내.png       ← 이미지 한 개가 연수 한 개
    안전교육/               ← 하위 폴더 한 개가 연수 한 개
      01.png
      02.png
      03.pdf
  data/                     ← 자동 생성: 서명과 열람 기록
```

- PDF, PNG, JPG, JPEG를 지원합니다. 암호가 걸린 PDF는 암호를 해제해서 넣어 주세요.
- 자료를 **추가·교체·삭제하면 열어 둔 연수 목록에 약 4초 안에 자동 반영**됩니다. 서버를 재시작할 필요가 없습니다. 관리자 화면은 새로고침 버튼으로 갱신합니다.
- 여러 이미지를 묶으려면 바로 아래 하위 폴더에 넣습니다. 파일 이름순으로 연결하므로 `01.png`, `02.png`처럼 번호를 붙여 주세요. PDF와 이미지를 섞어도 됩니다.
- 하위 폴더 안에 또 만든 폴더는 읽지 않습니다.
- 관리자 화면에서 연수명과 확인 문구를 수정할 수 있습니다. 자료 내용은 PDF·이미지를 교체해서 수정합니다.
- 파일·폴더 이름을 바꾸면 **새 연수**가 됩니다. 이름을 유지하고 파일을 교체하면 같은 연수의 새 자료 버전으로 처리됩니다.
- 자료를 교체하면 열람 중이던 참여자는 처음부터 다시 확인해야 합니다. 연수명·확인 문구를 변경해도 진행 중인 열람은 다시 시작해야 합니다.
- 삭제해도 **이미 받은 이름·서명·제출 당시 연수명·확인 문구·자료 버전**은 남습니다. 관리자의 ‘자료 삭제됨’ 항목에서 서명부를 받을 수 있습니다. 제출 당시 PDF 원본을 별도로 보관하지는 않으므로 필요하면 자료도 따로 백업하세요.

## 서명부 내려받기

관리자 화면에서 연수별로 **엑셀(.xlsx)** 또는 **워드(.docx)** 를 내려받습니다.
이름·직접 쓴 서명 이미지·제출 일시가 함께 들어갑니다. 제출이 추가되면 다시 내려받으세요. 기존에 내려받은 파일을 자동 수정하지는 않습니다.

같은 제출을 통신 오류로 다시 보내도 한 건만 저장합니다. 다른 열람에서 같은 이름으로 새로 제출하면 별도로 보관합니다. 동명이인도 있으므로 이름만으로 덮어쓰지 않습니다.
쪽 넘김 기록은 열람 확인용이며 실제 독서 여부나 서명자의 신원을 인증하지는 않습니다.

## 저장과 백업

- `data/training.sqlite3`에 이름·서명·제출 일시와 설정이 저장됩니다. 외부 서비스로 전송하지 않습니다.
- **서버를 종료한 뒤** 프로그램 폴더 전체를 복사하면 자료와 기록을 함께 백업할 수 있습니다.
- 다른 학교에 새 프로그램을 전달할 때는 `data`, `.venv`를 제외하세요. 해당 학교 자료로 `연수자료`를 바꾸면 됩니다.
- 자료 링크를 아는 교내 사용자는 열람과 제출이 가능합니다. 제출 목록과 내려받기는 **서버 PC의 localhost 관리자 로그인**으로만 가능합니다.
- 학교 내부망 HTTP용 프로그램입니다. 공유기 포트 포워딩으로 인터넷에 공개하는 용도로 만들지 않았습니다.

## 접속이 안 될 때

1. 서버 PC에서 `http://localhost:8000`이 열리는지 확인합니다.
2. Windows 방화벽에서 Python의 학교 내부망 연결을 허용합니다. 필요한 경우 학교 담당자에게 TCP 8000 포트 접속 허용을 요청합니다.
3. 교직원 PC와 서버 PC 사이 통신이 허용되는지 확인합니다. 게스트 Wi-Fi·망 분리 환경에서는 차단될 수 있습니다.
4. 서버 PC의 IP가 바뀌면 실행 창의 현재 IP를 다시 공유합니다.
5. 8000 포트가 사용 중이면 중복 실행된 서버를 종료하거나 포트를 바꿉니다.

포트나 관리자 비밀번호를 고정하려면 PowerShell에서 다음과 같이 실행합니다.

```powershell
$env:TRAINING_PORT = '8080'
$env:TRAINING_ADMIN_PASSWORD = '직접-정한-비밀번호'
.\서버실행.bat
```

## 개발 및 검증

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe server.py
```

서버: Flask + Waitress / 자료 처리: PyMuPDF / 저장: SQLite / 엑셀: openpyxl / 워드: python-docx.
이전 구글 연동 버전인 루트의 `index.html`, `config.js`, `apps-script/`는 참고용으로 남아 있으며 로컬 서버에서는 사용하지 않습니다.
