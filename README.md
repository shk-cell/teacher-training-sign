# 교사연수서명프로그램 (teacher-training-sign)

교직원이 온라인으로 연수 자료를 읽고, 확인 문제를 풀고, 서약 서명을 제출하는 사이트입니다.
사이트는 **GitHub Pages**에 올리고, 제출 내용은 담당자의 **구글 시트**에 저장됩니다.
담당자는 시트 메뉴에서 **서명부(구글 문서)**를 만들어 PDF로 내부결재에 첨부합니다.

```
교직원 브라우저 ──(제출)──▶ Google Apps Script 웹 앱 ──▶ 구글 시트 '제출' + 드라이브 서명 이미지
     ▲                                                          │
GitHub Pages (index.html, config.js)                시트 메뉴 → 서명부 구글 문서 → PDF
```

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 연수 화면 (교육 자료 → 확인 문제 → 서약·서명) |
| `config.js` | 연수 제목, 교육 자료, 확인 문제, 제출 주소. **연수가 바뀌면 이 파일만 고칩니다.** |
| `apps-script/Code.gs` | 구글 시트에 붙여 넣을 Apps Script (제출 저장, 서명부 만들기) |

## 설치 순서

### 1. 구글 시트 준비
1. 학교(기관) 구글 계정으로 새 구글 시트를 만듭니다. 예: `2026 교사연수 서명`
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 지우고 이 저장소의 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장합니다.
4. 함수 선택에서 `setup`을 고르고 **실행**합니다. 권한 승인 창이 뜨면 본인 계정으로 허용합니다.
   → 시트에 `제출` 탭이, 드라이브에 `교사연수서명_서명이미지` 폴더가 생깁니다.

### 2. 웹 앱으로 배포
1. Apps Script 화면 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형 선택에서 **웹 앱**을 고릅니다.
3. **실행 사용자: 나**, **액세스 권한: 모든 사용자**로 설정하고 배포합니다.
   - "모든 사용자"여야 교직원이 구글 로그인 없이 제출할 수 있습니다.
   - 학교 계정 사용자만 받으려면 "○○ 도메인 내 모든 사용자"를 고르세요. 이때는 교직원이 학교 구글 계정으로 로그인한 브라우저에서만 제출됩니다.
4. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

### 3. config.js 설정
`config.js`의 `SCRIPT_URL`에 복사한 주소를 넣습니다.

```js
SCRIPT_URL: "https://script.google.com/macros/s/AKfy.../exec",
```

### 4. GitHub Pages 켜기
1. 이 저장소를 GitHub에 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 저장합니다.
3. 1~2분 뒤 `https://<계정>.github.io/teacher-training-sign/` 주소가 생깁니다. 이 주소를 교직원에게 보냅니다.

### 5. 서명부 만들기 (연수가 끝난 뒤)
1. 구글 시트를 새로 고치면 메뉴에 **교사연수 서명**이 생깁니다.
2. **교사연수 서명 → 서명부 만들기**를 누르고 연수ID, 전체 대상 인원, 기관명을 입력합니다.
3. 만들어진 구글 문서를 **파일 → 다운로드 → PDF**로 저장해 결과보고에 첨부합니다.
   - 같은 사람이 여러 번 제출했으면 마지막 제출만 서명부에 들어갑니다.

## 다음 연수에 다시 쓰기
`config.js`에서 아래 항목을 바꾸고 커밋하면 됩니다. 같은 시트에 계속 쌓이며, 서명부는 연수ID별로 만들어집니다.

- `COURSE_ID`: 새 값으로 바꿉니다. 예: `2027-security`, `2026-child-abuse`
- `TITLE`, `EYEBROW`, `META`, `PLEDGE`, `MODULES`, `QUIZ`

## 개인정보 주의
- **이 저장소에는 개인정보가 들어가지 않습니다.** 제출 내용은 담당자 구글 시트와 드라이브에만 저장됩니다.
- GitHub 무료 계정의 Pages는 저장소가 **공개(public)**여야 합니다. `config.js`에 개인정보나 내부 자료를 넣지 마세요.
- 웹 앱 URL을 아는 사람은 누구나 제출할 수 있습니다. 링크는 교내 메신저나 업무 메일로만 보내세요.
- 연수가 끝나고 보존기간이 지나면 시트의 행과 드라이브 서명 이미지를 지웁니다.
- 기관 지침상 구글 서비스에 교직원 개인정보를 저장해도 되는지 정보보안 담당자에게 먼저 확인하세요.
